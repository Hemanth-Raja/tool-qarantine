Tool Quarantine

Sandbox every agent tool before it touches your machine.

Hemanth Raja · Poojitha Kattagithub.com/Hemanth-Raja/tool-qarantine
The problem

Agents install tools from strangers.
Nobody checks what they actually do.

Trust by descriptionAn MCP server tells the agent what it does in a sentence. Users approve that sentence, not the code.
Full blast radiusThe tool runs with the user's files, SSH keys, cloud credentials and network. One bad tool can reach all of it.
Real attacksTool poisoning, credential exfiltration, DNS smuggling, rug pulls and persistence already target agent tooling.
The solution

Watch it run in a sealed box. Then decide.

01QuarantineFresh container: no internet route, read-only disk, capabilities dropped, decoy credentials planted.
02ExerciseAn agent on Vultr Serverless Inference reads the tool's description and uses it like a real user.
03Observestrace records every file and process. A sinkhole answers DNS and HTTP and keeps what the tool tries to send.
04DecideClaims vs. reality, a trust score, workspace policy, approve or block. Then the box is destroyed.

The product

A trust report, not a scan score

Live activityWatch file reads, credential access, DNS and POSTs stream in, then replay the run for your team.
Claims vs. realityEach area the tool's description mentions or denies, next to what it actually touched. Over-reach is flagged.
Blast radiusA map of everything it reached for and where the sandbox wall stopped it.
Code-pinned registryApproval pins the sha256 of the code. Change one byte and it must be quarantined again: no rug pulls.
PoliciesAuto-block exfiltration, credential theft, poisoning, persistence. Require reasons. Expire approvals.
IntegrationsOne HTTP call for MCP gateways, a CLI check, and a GitHub Actions gate. JSON / PDF audit export.

Built on Vultr

Every run is disposable

Vultr Cloud ComputeThe orchestrator, the per-run sandbox containers and the DNS / HTTP / TLS sinkhole run on a Vultr VM in Frankfurt. Each run gets its own internal network with no route out, and it is destroyed afterwards.
Vultr Serverless InferenceThe agent that exercises each tool is an LLM on Vultr Serverless Inference (OpenAI-compatible API, model qwen3.8-27b). It reads the tool's own description and plans realistic calls, the way a user's agent would.
StackPython · FastAPI · Docker · strace · official MCP SDK · a custom MCP stdio client · plain HTML/JS console. 28 automated tests, plus Docker integration tests.
