Don't install an agent tool until you've watched it run.

Tool Quarantine runs an untrusted MCP server inside a disposable, network-sinkholed sandbox, lets an AI agent use it like a real user would, and records every file it opens and every host it tries to reach. Then it shows you what the tool claims next to what it actually did.

02ExerciseAn agent on Vultr Serverless Inference calls the tool with realistic inputs.
03Observestrace on every syscall; a sinkhole answers DNS and captures any outbound data.
04DecideClaims vs. reality, a trust score, and an approve / reject decision. Box destroyed.
